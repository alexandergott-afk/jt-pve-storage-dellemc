# Quick Start

> **Status: skeleton (Phase 0).** Written in Phase 4, once the
> `dellpowerstore` type exists. 繁體中文：[QUICKSTART_zh-TW.md](QUICKSTART_zh-TW.md)

Planned outline:

1. Prerequisites — PVE 9.1+, PowerStore OS 3.0+, network paths to the array.
2. Install the package on every cluster node.
3. Create a REST API account on PowerStore with the minimum required role.
4. Prepare iSCSI or FC connectivity on the nodes.
5. `pvesm add dellpowerstore ...`
6. Verify: `pvesm status`, create a test disk, confirm the multipath device.
7. Where to go next: CONFIGURATION.md, TROUBLESHOOTING.md.
