# 快速上手

> **狀態：骨架（Phase 0）。** 待 Phase 4 完成 `dellpowerstore` type 後撰寫。English: [QUICKSTART.md](QUICKSTART.md)

預計章節：

1. 前置需求 — PVE 9.1 以上、PowerStore OS 3.0 以上、節點到陣列的網路路徑。
2. 在叢集每一台節點安裝套件。
3. 在 PowerStore 建立 REST API 帳號，並給予最小必要角色。
4. 在節點上準備 iSCSI 或 FC 連線。
5. 執行 `pvesm add dellpowerstore ...`。
6. 驗證：`pvesm status`、建立測試磁碟、確認 multipath 裝置出現。
7. 後續閱讀：CONFIGURATION_zh-TW.md、TROUBLESHOOTING_zh-TW.md。
